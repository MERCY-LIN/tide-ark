# 潮汐方舟 · Tide Ark

> 横板 · 配置构筑 · 自动战斗 · 单文件离线可玩

一个「把广告里的画面做成真正玩法」的小游戏原型。

![建造阶段](docs/build.png)
![战斗阶段](docs/battle.png)

---

## 这是什么

你在一个被淹没的世界里，把一块破木筏一点点改造成战舰。

**退潮**时打捞、建造；**涨潮**时海怪从左右两舷和水下扑上来，你装上的模块自动开火。
撑过 8 次潮汐。

没有操作，只有配置。乐趣在于：**你摆的每一门炮，决定了这一波能不能守住。**

---

## 直接玩

两种方式，都不需要构建、不需要 npm、不需要联网：

| 方式 | 文件 | 说明 |
|---|---|---|
| **推荐** | `standalone.html` | 单个 HTML，约 75 KB，双击即玩，断网可用 |
| 开发 | `index.html` | 拆分版（`style.css` + `data.js` + `core.js` + `app.js`），改完刷新即可 |

重新生成单文件版：

```bash
node tools/build-standalone.js
```

## 玩法

| 阶段 | 你做什么 |
|---|---|
| **建造** | 花木材把模块放到甲板格子里，点「涨潮」开战 |
| **迎战** | 模块自动开火，你只能看（可 2 倍速） |
| **打捞** | 三选一：新模块 / 木材 / 修复，然后进入下一次潮汐 |

### 三层甲板 = 三条泳道

这是整个游戏的核心规则：

- **高空甲板** 只能打**空中**（潮蝠）
- **主甲板** 只能打**海面**（漂流者、甲壳兽、掠夺艇）
- **水下舱** 只能打**水下**（深潜者）

### 左右舷：射程按「列」算

武器**打不到对侧**。靠左的炮只能覆盖左舷，靠右的只能覆盖右舷，
中间的炮两边都能顾一点，但覆盖都很浅。

每波来袭方向会提前标在画面上（← 左舷 / 右舷 →），
所以「这一波从哪边来」直接决定了你该把炮摆在哪。

### 潮汐：一条会涨的水位线

- 潮水涨满还没清场 → 敌人**狂暴**、船舱**持续进水**，基本必死
- 主甲板在潮位过高时**进水**，射速变慢
- **抽水泵**能拖慢涨潮速度，给你更多清理时间

### 其他

- **供电**：每层放一台发电机，否则这一层武器射速 -28%
- **弹药库**：相邻武器伤害 +25%（最多 +50%）
- **下潜**：花一次机会换 25 木材，但下一波会多来 2 只深潜者

失败后会给归因：这一局主要被哪条泳道打穿、为什么。

## 设计笔记

这个项目的起点是《疯狂水世界》的广告：广告里是海上求生、捞海水过滤器、住进高级庇护所，
实际进游戏是纯数值卡牌挂机。广告和游戏是两条平行线。

于是我试着反过来做：**把那支 15 秒广告里的每个画面，都做成真实的系统。**

| 广告里的瞬间 | 在这里是什么 |
|---|---|
| 从水里捞起过滤器 | 每波结束的三选一打捞 |
| 住进高级庇护所 | 木筏一格格被你自己扩建出来 |
| 水位上涨、怪物围上来 | 潮汐就是波次计时器，也会真的淹没甲板 |
| 潜下去看深海 | 「下潜」换资源，但要拿下一波的安全去赌 |
| 「启动！」 | 撑过第 8 次潮汐 |

**参考游戏**：Loop Hero（无操作构筑循环）、剑与远征（横板自动战斗的表现层）、
Slay the Spire（三选一 + 路线）、Kingdom（横板发展自动化）。

## 技术架构

刻意做成三层，**逻辑层零渲染依赖**：

```
data.js   纯数值表：模块 / 敌人 / 波次
core.js   纯逻辑：建造校验、供电、潮汐战斗模拟（确定性，不碰 DOM）
app.js    渲染与交互：Canvas 场景 + DOM 面板
```

好处：

- **可以 headless 跑**：`tools/balance.js` 用贪心 AI 打 400 局，1 秒出胜率曲线
- **可以倍速/跳过**：渲染只是订阅 `step()` 产出的状态和事件
- **可以整局回放**：状态可序列化（后续接 IndexedDB 存档）

画布固定 1120×560，全部矢量绘制，**没有任何图片/音频资源**，所以单文件只有 75 KB。

## 数值回归

```bash
node tools/balance.js 400          # 批量跑 400 局
node tools/balance.js 1 --trace    # 跑 1 局并打印 W8 的甲板与逐秒战况
```

当前调校结果（400 局，贪心 AI）：**通关率约 74%**，绝大多数失败发生在第 8 波 Boss。
AI 大致相当于一个「懂规则但不会精算」的玩家。

调平衡时优先改 `data.js`，不要改 `core.js`。

### 调试参数

开发时可以直接跳到某个状态：

```
index.html?nointro=1                 跳过开场说明
        &demo=1                       预置一套甲板
        &battle=1&sim=12              直接开战并快进 12 秒
        &wave=5                       从第 5 波开始
        &reward=1                     直接看打捞弹窗
```
