# 潮汐方舟 · Tide Ark

> 横板 · 配置构筑 · 自动战斗 · 单文件离线可玩

一个「把广告里的画面做成真正玩法」的小游戏 — **v0.3**

![建造阶段](docs/build.png)
![战斗阶段](docs/battle.png)

## 这是什么

你在一个被淹没的世界里，把一块破木筏一点点改造成战舰。

**退潮**时打捞、加固甲板、装模块；**涨潮**时海怪从左右两舷和水下扑上来，你装上的东西自动开火。
每撑过一次潮汐，你都要为下一场选一条路——**更凶的敌人，换更好的东西**。

没有操作，只有配置与取舍。

## 直接玩

| 方式 | 文件 | 说明 |
|---|---|---|
| **推荐** | `standalone.html` | 单个 HTML，约 93 KB，双击即玩，断网可用 |
| 开发 | `index.html` | 拆分版（`style.css` + `data.js` + `core.js` + `app.js`），改完刷新即可 |

重新生成单文件版：

```bash
node tools/build-standalone.js
```

## 一局长什么样

```
选船 → 建造 ⇄ 迎战 → 选路线 → 建造 ⇄ 迎战 → 选路线 → … → 第 8 次潮汐（Boss）
         ↑                                              ↑
      一路攒下的遗物、改造、模块，决定你能不能走到这里
```

### 1. 选船：这一局的起点不一样

![选船](docs/ship.png)

| 船 | 甲板 | 木材 | 耐久 | 特点 |
|---|---|---|---|---|
| **驳船** | 4 列 | 38 | 200 | 宽、厚，但穷 |
| **炮艇** | 2 列 | 56 | 140 | 窄、薄，所有武器伤害 +25% |
| **母舰** | 3 列 | 44 | 170 | 开局白送 2 个随机模块 |

起点不同，能走的路就不同——炮艇逼你少而精，驳船逼你精打细算。

### 2. 路线：明牌的取舍

![路线](docs/route.png)

每撑过一次潮汐，都要从 2–3 条路里挑一条。**难度是明牌，奖励也是明牌，但你只能选一场。**

| 类型 | 难度 | 奖励 |
|---|---|---|
| 平静潮汐 | 敌方生命 -18% | 木材 / 修复 |
| 寻常潮汐 | 标准 | 一个模块 |
| 强袭 | 生命 +20%，多 1 个单位 | 一个全局改造 |
| 精英潮 | 生命 +38%，多 2 个单位 | **一个遗物** |

想变强就得主动挑硬的打——这是每局节奏由你自己定的地方。

### 3. 遗物：整局改变规则

精英潮才掉，一共 12 个，效果都不是数值：

> 探照灯（射程 +1 列）· 铁甲船首（耐久 +60）· 潮汐之子（满潮敌人不再狂暴）
> · 扩建图纸（加固费用 -40%）· 双联装（弹药库加成翻倍）· 排水泵（潮速 -15%）…

拿到哪个是随机的，所以每局的「强势打法」都不一样。

## 战斗的规则

### 三层甲板 = 三条泳道

- **高空甲板** 只能打**空中**（潮蝠）
- **主甲板** 只能打**海面**（漂流者、甲壳兽、掠夺艇）
- **水下舱** 只能打**水下**（深潜者）

### 左右舷：射程按「列」算

武器**打不到对侧**。靠左的炮覆盖左舷，靠右的覆盖右舷。
没加固外侧列，就够不着远处的敌人——所以「往哪边扩」是一次真实的空间决策。

### 甲板就是资源

开局只有中间几列，两侧是断的，要花木材**加固**（内侧 30 / 外侧 50，每列 +3 格 + 耐久）。

### 潮汐词条

第 4 波起，约 60% 的潮汐会带一个词条：

| 词条 | 效果 |
|---|---|
| 逆流 | 敌方移速 +35% |
| 浓雾 | 所有武器射程 -20% |
| 铁潮 | 敌方生命 +30% |
| 蜂群 | 敌方数量 +3，生命 -25% |
| 血月 | 敌方啃咬伤害 +50% |
| 暗流 | 额外 2 只深潜者 |

### 满潮

潮水涨满还没清场 → 敌人**狂暴** + 船舱**持续进水**，基本必死。
主甲板在潮位过高时也会进水、射速下降。**抽水泵**和「排水泵」遗物能拖时间。

## 设计笔记

起点是《疯狂水世界》的广告：广告里是海上求生、捞海水过滤器、住进高级庇护所，
实际进游戏是纯数值卡牌挂机。广告和游戏是两条平行线。

于是反过来做：**把那支 15 秒广告里的每个画面，都做成真实的系统。**

| 广告里的瞬间 | 在这里是什么 |
|---|---|
| 从水里捞起过滤器 | 每波结束的打捞 |
| 住进高级庇护所 | 木筏一列列被你自己加固出来 |
| 水位上涨、怪物围上来 | 潮汐就是波次计时器，也会真的淹没甲板 |
| 潜下去看深海 | 「下潜」换资源，但要拿这一波的安全去赌 |
| 「启动！」 | 撑过第 8 次潮汐 |

**参考游戏**：Loop Hero（无操作构筑循环）、剑与远征（横板自动战斗的表现层）、
Slay the Spire（路线选择 + 明牌取舍）、Kingdom（横板发展自动化）。

### 版本演进

- **v0.1** 波次写死 8 条，甲板一开始就满格 —— 每局一模一样，第二遍没有决策
- **v0.2** 随机波次 + 词条 + 甲板从 6 格起步 + 全局改造 —— 有变数了，但**还是一局同一种玩法**
- **v0.3** 选船 + 路线选择 + 遗物 —— 这才补上 rogue 的骨架：
  **起点不同、路径不同、拿到的东西不同，所以每局的故事不同**
- **v0.3.1** 修三个真 bug：构建阶段每帧抛异常导致画面冻结、右舷敌人没翻转朝向、波次计数提前 +1

## 技术架构

三层，**逻辑层零渲染依赖**：

```
data.js   纯数值表：模块 / 敌人 / 词条 / 改造 / 遗物 / 起始船 / 波次与路线生成器
core.js   纯逻辑：扩建、建造、潮汐战斗模拟（确定性，不碰 DOM）
app.js    渲染与交互：Canvas 场景 + DOM 面板
```

好处：

- **可以 headless 跑**：`tools/balance.js` 用贪心 AI 打几百局，1 秒出胜率曲线
- **可以倍速/瞬间结算**：渲染只是订阅 `step()` 产出的状态和事件
- **可复现**：同一 seed + 同一串选择 = 同一局

画布固定 1120×560，全部矢量绘制，**没有任何图片/音频资源**。

## 数值回归

```bash
node tools/balance.js 300          # 批量跑 300 局
node tools/balance.js 1 --trace    # 跑 1 局，打印最终甲板 / 遗物 / 词条 / 逐秒战况
```

当前调校（300 局，贪心 AI）：**通关率约 55%**，
死亡分布在第 4–8 波，第 5 波（深潜者登场）和第 8 波 Boss 是两道坎。

调平衡只改 `data.js`，不要动 `core.js`。
